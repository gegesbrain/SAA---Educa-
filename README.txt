SAA - Protótipo Web

Educa+ é um sistema feito por estudantes do curso técnico em Informática 
para atividade avaliativa da disciplina de Análise e Desenvolvimento de 
Sistemas.

===================================================================

Arquivos:
- index.html
- style.css
- script.js
- educalogo.png

Pastas:
- img

Como usar:

1. Extraia a pasta.
2. Abra index.html no navegador.
3. O sistema funciona sem servidor e sem banco de dados.

Funções demonstradas:
- Dashboard
- Cadastro/remoção de alunos
- Cadastro/remoção de professores
- Cadastro/remoção de disciplinas
- Lançamento de notas
- Controle de frequência
- Matrículas
- Atividades
- Avisos
- Relatórios para impressão
- Configurações
- Responsividade para celular
